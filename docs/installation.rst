Installation
============

Before installing is recomended to create a virtual environment. You can do this by running the following command in your terminal::
    conda create --name atunapy_new  python>=3.8 pip
    conda activate atunapy_new

Install from PyPI::

    pip install atunapy

Install from source::

    git clone https://github.com/aylindmm/aTUNApy.git
    cd aTUNApy
    pip install -e .
